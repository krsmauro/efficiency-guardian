bloqueé el acceso a youtube en mi macbook pro usando el archivo hosts en etc, necesito youtube, cómo puedo desbloquearlo

Explicando cómo desbloquear YouTube editando el archivo hosts.

Para desbloquear YouTube tienes que quitar las líneas que añadiste al archivo /etc/hosts y luego limpiar la caché DNS de macOS.

1. Edita el archivo hosts

Abre Terminal (Cmd + Espacio, escribe “Terminal”) y ejecuta:

bash
sudo nano /etc/hosts

Te pedirá tu contraseña de usuario de la Mac. Mientras la escribes no se ve nada en pantalla; es normal.

2. Elimina o comenta las líneas de YouTube

Busca líneas parecidas a estas:

127.0.0.1   youtube.com
127.0.0.1   www.youtube.com
0.0.0.0     m.youtube.com
0.0.0.0     youtu.be

Puedes borrarlas o ponerles un # al inicio para desactivarlas. Con # es más fácil volver a bloquear después:

# 127.0.0.1   youtube.com

Revisa también si bloqueaste dominios relacionados como ytimg.com, googlevideo.com o youtube-nocookie.com, porque sin ellos los videos no cargan aunque la página abra.

No toques las líneas originales del sistema (127.0.0.1 localhost, 255.255.255.255 broadcasthost, ::1 localhost).

Para guardar en nano: presiona Ctrl + O, luego Enter, y después Ctrl + X para salir.

3. Limpia la caché DNS
bash
sudo dscacheutil -flushcache; sudo killall -HUP mDNSResponder
